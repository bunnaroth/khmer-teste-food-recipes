Taste of Cambodia

A Cambodian food and culture magazine for discovering traditional dishes, ingredients, recipes, and culinary stories. This is an editorial platform, not a restaurant ordering site.

Routes:
  / — Homepage with featured dishes and categories
  /story — Cambodian cuisine and pantry ingredients
  /cuisine — Searchable and filterable recipes
  /cuisine/[slug] — Recipe details and cooking instructions
  /culture — Food and culture journal
  /culture/[slug] — Full articles and related content

Tech Stack:
  Next.js (App Router) + TypeScript
  Tailwind CSS
  Local TypeScript content in src/data
  Local images in src/assets/images

Getting Started:
  npm install
  npm run dev

Visit http://localhost:3000.

Validation:
  npm run lint
  npm run content:check
  npm run build
